# 调研与选型记录

[文档目录](../README.md)

这些文件记录 2026-10-24 的研究依据，保留已检查的上游版本、文档来源和实验边界。当前产品已迭代，功能清单应以 [产品设计](../product-design.md) 与 [技术方案](../technical-design.md) 为准。

| 记录 | 主要结论 |
| --- | --- |
| [本地 ASR](local-asr.md) | 复用 Handy 的兼容 Whisper GGML 文件；豆包输入法没有核实可供本项目调用的离线接口 |
| [背景声音与人物](background-audio.md) | 能量、VAD、分段、声纹与音源分离是不同问题，不能把一个门槛当成对话范围识别 |
| [DJI Mic 3 / micSync](mic-sync.md) | 当前落地的是本地 WAV/设备输入；未实现 Mic 3 无线内录自动下载 |

上游项目可能更新，历史源码引用应按记录的提交或版本复查。研究用的第三方源码快照、测试录音和模型权重不随本仓库分发。外部硬件尚未验收的能力不会因为存在官方功能描述而写成 Audio Agent 已实现。
