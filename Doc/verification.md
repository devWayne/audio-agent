- 采集与分段：显式启动、输入设备、启动超时、动态声音边界、静音不落盘、停止保存末段、过载停止、阈值在声段边界生效。
- 存储：音频格式、导入去重、稳定文件检测、源文件保留、时间窗口、缺口、保留期、SQLite 索引、并发锁、空间不足。
- 推理隔离：缺模型/缺运行时、子进程错误与超时、非标准输出隔离、临时结果清理、ASR 与说话人共享锁直至持久化。

- MCP：真实 stdio initialize/list/call、已有文字读取、增量游标、等待、过期游标、无隐式模型/麦克风副作用。

## 交互验收

### 文档与人物

已在隔离库中验证 WAV 导入、原文显示、单段/全文复制、下载、人物登记入口、其他人物备注修改与移除、后补标签。公开样例不作为用户本人声纹登记。真实人物向量、日常录音与截图不纳入公开仓库。

### 本人多参考声纹

- 隔离浏览器使用合成 PCM 与合成向量，不冒充真实人物准确率测试。确认默认追加把 1 段参考变为 2 段、保留旧样本；逐条移除后保留其余样本与原录音；“查看录音”打开对应片段；改为整组替换会清除勾选状态，要求重新确认。
- 后台匹配测试验证按有效时长加权（单样本权重封顶 10 秒），不会因对平均向量再次归一化而把不达标的相似度抬高；短参考可登记，原匹配门槛继续保留。
- 正式更新前停止当前监听，等录音保存、转写和说话人队列全部结束，再正常退出旧后台；通过原有已授权菜单栏应用启动新后台。随后恢复原麦克风、语言、VAD 与音量门槛，实测收到新的 PCM，状态无错误。
- 正式页面确认出现样本列表与追加入口。读取前后的本人参考文件 SHA-256 一致；没有替用户添加、移除或替换真实声纹。此结果证明兼容与交互生效，不证明多参考已提高该用户的识别命中率。
- 合成界面验收服务已结束。现有外部 MCP 进程若仍运行旧代码，需重连后才能读取未来保存的 v2 多参考资料。

### 动态分段与门槛

合成 PCM 检查：120 秒静音不产生文件、不调用 ASR；45 秒连续声音在停顿/停止前不周期性切片；两段分离的活动各生成一段。该结果不是“能过滤所有电视台词”的证明。

菜单栏门槛通过辅助功能增减与鼠标轨道点击验证自动保存，并与 Web 已保存值同步；Web 未保存草稿不会被另一个客户端更新覆盖。连续拖动的自动化操作未成功改变原生控件，因此不把该动作列为实测通过。

### 存储与 MCP 页

隔离库完成真实浏览器“复制现有资料并切换”：新旧 WAV 内容一致，源目录保留，转写继续可读，临时服务已结束。正式库保持项目 `.data`，没有为了验收搬动真实资料。

生产控制台验证 `#storage` 和 `#mcp` 独立页，当前目录/默认目录均为项目 `.data`。Claude Code 和 Codex 配置复制到剪贴板后逐字校验，随后恢复原剪贴板；没有因此修改外部客户端或声称两者均已连接。

### 菜单栏版本边界

菜单栏 `0.1.4 (5)` 的存储入口已经实机打开正确页面。最新源码随后增加默认目录/异步解析调整，独立编译和测试通过；当时运行中的已授权应用保持原版本，以免再次改签名。当前机器已有 `.data`，两者解析到同一资料库。源码修改、构建成功和正在运行的二进制版本是三件不同的事。
